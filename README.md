# BazarBondhu (বাজারবন্ধু)

বাংলাদেশের বাজারদর ও দাম তুলনার অ্যাপ।

## প্রাথমিক লক্ষ্য
- প্রাথমিক বাজার: কারওয়ান বাজার, ঢাকা
- ভাষা: বাংলা
- মুদ্রা: BDT (৳)

## ⚠️ গুরুত্বপূর্ণ সতর্কতা

**এই অ্যাপের সব দাম ডেমো — বাস্তব বাজারদর নয়।**
বাস্তব দাম শুধু ব্যবহারকারীর যাচাইকৃত রিপোর্ট থেকে যোগ করা হবে।

## ডেভেলপমেন্ট

এই প্রজেক্টটি শুধু Android ফোন + Termux দিয়ে তৈরি করা হচ্ছে।
বিল্ড হয় GitHub Actions এ (মেঘে), ফোনে নয়।
